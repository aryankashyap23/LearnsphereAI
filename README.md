# LearnSphere AI – An Intelligent Learning & Career Development Platform

**LearnSphere AI is a next-generation, AI-powered learning platform designed to transform how students learn, practice, and prepare for their careers.**

It brings together intelligent tutoring, personalised learning resources, interactive assessments, and AI-driven mock interviews into one unified learning ecosystem.

Unlike traditional e-learning platforms, LearnSphere AI goes beyond simply delivering educational content. It helps learners understand concepts more deeply through a timestamp-aware AI teaching assistant that can answer questions based on video lessons and relevant course materials.

The platform empowers students to upload and explore learning resources, access lecture videos, generate AI-powered quizzes, evaluate their knowledge, and practice real-world technical interviews with structured AI feedback.

### Key Features

- **AI-Powered Learning Assistant:** Provides contextual explanations and answers based on lesson content, playback timestamps, and relevant study materials.
- **Smart Course Management:** Enables teachers to organise courses, upload educational videos, and manage learning resources.
- **Intelligent Resource Management:** Supports PDF and PowerPoint uploads, text extraction, and content-based retrieval.
- **AI-Generated Quizzes:** Creates topic-relevant assessments with automated scoring and detailed explanations.
- **AI Mock Interview Simulator:** Generates role-specific technical interview questions and evaluates answers based on relevance, clarity, and technical depth.
- **Learning Analytics & Progress Tracking:** Maintains learning history, quiz performance, interview results, and improvement recommendations.
- **Multi-Role Authentication:** Provides separate student and teacher experiences with email/password authentication and optional Google sign-in.

### Technology Stack

**Frontend:** React.js, TypeScript, Vite, Tailwind CSS

**Backend:** Python, FastAPI, REST APIs

**Database:** SQLite

**Artificial Intelligence:** OpenAI API, Google Gemini API

**AI Architecture:** Retrieval-Augmented Generation (RAG), TF-IDF, Cosine Similarity

**Authentication:** Firebase Authentication (optional Google OAuth), backend email/password authentication

**Additional Technologies:** Python-PPTX, PyPDF, Edge TTS, Docker

### Project Vision

LearnSphere AI aims to bridge the gap between traditional education and industry-ready skills by creating an interactive environment where learners can study smarter, assess their knowledge, and build confidence for technical interviews.

**Learn. Practice. Evaluate. Get Career-Ready.**
